# Next Step Bot — Documentation

The public policy documents for **Next Step Bot**, the Discord bot built by
[Next Step Studios](https://github.com/Next-Step-Studios-Official) for its own private Discord server.

The bot is in development and is not publicly installable. This repository holds its
documentation only — no bot source code.

---

## Status: drafts, not yet in force

Every document here is **version 0.2.0, draft for review, not yet effective**.

They have no effective date and do not yet represent operative policies. They are published
so the documents have stable, linkable locations while the bot's implementation is verified.
Nothing in this repository claims legal compliance, and describing a planned feature is not a
statement that the feature operates today.

## Contact

Questions, corrections, or privacy requests concerning the bot go by email to
**nextstepstudiosofficial.contact@gmail.com**, operated by Candler Shaw under the public-facing
name Next Step Studios.

For a privacy request, use the subject line **Privacy Request**, include your Discord user ID,
and say whether you are asking for access, correction, or deletion. Never send passwords, bot
tokens, API keys, or Discord account credentials — no legitimate request requires them.
